# Angels Knoll Drawing Set

Site plans, sections and elevations of Angels Knoll (Bunker Hill Parcel Y-1, 361 S. Hill St, Los Angeles), drawn from real GIS data, with sourced stakeholder records pinned at their real locations.

Sheets: A1.01 site plan (context) · A1.02 parcel plan (topography) · A2.01 Section A-A · A2.02 Section B-B (Angels Flight) · A3.01 south elevation (4th St) · A3.02 east elevation (Hill St). Styles: Technical, Night, Diagram.

## Data

- Ground: LA County LARIAC 2-ft contours (Elevation MapServer, layer 4)
- Buildings: LA County LARIAC 2020 building footprints with measured heights
- Parcels: LA County Assessor parcels (APN 5149-010-951, -952, -265)
- Streets, Angels Flight track, Metro entrances: (c) OpenStreetMap contributors (ODbL)
- Landmark locations: OpenStreetMap Nominatim

Sections are at true scale (1:1) by default; a 2x option is labeled as exaggerated. Research current as of September 28, 2026.
